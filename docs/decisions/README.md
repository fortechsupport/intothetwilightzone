# Decision records

One file per decision: `NNNN-short-name.md` with the date, who decided, the decision, **Why**, and **Set
aside** (the options rejected and the reason for each). When a later decision changes an earlier one, add a
dated "Amended by" line at the top of the earlier record. Rules already decided by Adam are summarized in
CLAUDE.md; backfilling a record for each is on the list.
